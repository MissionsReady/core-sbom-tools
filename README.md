# core-sbom-tools

Lean Python 3 tooling for strict, deterministic, per-platform SPDX 2.3 JSON
evidence generated by a pinned Syft release. The accepted output remains an
SPDX JSON document (`application/spdx+json`) so it can be referenced directly
by the `core-blueprints` `evidence.sboms` contract.

The implementation uses only the Python standard library and performs no
network access.

## Quick start

Generate raw SPDX JSON with the workflow's digest-pinned Syft binary, ensuring
that the SPDX document name is the immutable OCI reference:

```sh
syft ghcr.io/missionsready/example@sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa \
  -o spdx-json=raw.spdx.json
```

Create strict source metadata:

```json
{
  "type": "oci-image",
  "name": "ghcr.io/missionsready/example",
  "reference": "ghcr.io/missionsready/example@sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "digest": "sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "platform": "linux/amd64"
}
```

Normalize and optionally compare with the previous accepted platform SBOM:

```sh
scripts/sbom-tool normalize \
  --input raw.spdx.json \
  --output accepted.spdx.json \
  --subject-name ghcr.io/missionsready/example \
  --subject-digest sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa \
  --platform linux/amd64 \
  --syft-version 1.30.0 \
  --source-metadata source.json \
  --previous previous.spdx.json \
  --report delta.json
```

The human summary is written to stderr. Canonical SPDX and delta JSON files are
staged, file-and-directory fsynced, and committed as one recoverable
transaction, including when outputs use different directories. Separate
operations are also available:

```sh
scripts/sbom-tool validate --input accepted.spdx.json
scripts/sbom-tool compare --previous previous.spdx.json --current accepted.spdx.json --report delta.json
```

Use the library from `src` with `build_evidence`, `validate_evidence`,
`compare_evidence`, and `load_json_strict`, or install it with a normal Python
installer using `pyproject.toml`.
